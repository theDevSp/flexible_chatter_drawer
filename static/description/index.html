🎯 Flexible Chatter Drawer

Transform your Odoo chatter into a beautiful, customizable floating drawer!

Perfect for Odoo 18.0 • Clean Interface • Fully Customizable • Zero Code Required

✨ Why Flexible Chatter Drawer?

The Flexible Chatter Drawer revolutionizes how you interact with Odoo's chatter system. Instead of cluttering your form views, the chatter elegantly slides in from the side when needed, giving you maximum screen real estate while keeping all communication features just a click away.

🚀 Key Features

🎨Colors & Design

  • Button Gradients: Choose your primary and secondary colors for beautiful gradient effects
  • Drawer Background: Customize the drawer background to match your theme
  • Icon Selection: Choose from 7 different icons for the floating button
  • Dark Mode: Automatic dark mode support with customizable colors

📐Sizing & Dimensions

  • Button Size: Set the perfect size for your floating button (50-80px recommended)
  • Border Radius: Make it circular (50%) or squared (0-50%)
  • Drawer Width: Control how much screen space the drawer takes (30-70% desktop, 100% mobile)
  • Shadow Effects: Choose from none, small, medium, or large shadow effects

📍Positioning

  • Button Position: Bottom-right, Bottom-left, Top-right, or Top-left
  • Drawer Side: Slide in from left or right
  • Custom Offsets: Fine-tune the exact position from edges
  • Z-Index Control: Manage layering for complex layouts

✨Effects & Animations

  • Slide Animations: Smooth slide-in/out transitions
  • Pulse Effect: Attention-grabbing pulse on the button
  • Overlay Effect: Optional dimmed overlay when drawer is open
  • Animation Speed: Control how fast animations play

⚙️ Easy Configuration

No coding required! Simply go to Settings → Technical → Chatter Drawer → Configuration and customize every aspect through our intuitive interface:

Colors Tab

Visual color picker for all color options

Sizing Tab

Sliders and inputs for precise sizing

Position Tab

Dropdown selectors for easy positioning

Effects Tab

Toggle animations and effects on/off

Advanced Tab

Model exclusions and custom CSS

📦 Installation

  1. Download the module from Odoo Apps Store
  2. Install it in your Odoo instance (Apps → Install)
  3. Go to Settings → Technical → Chatter Drawer → Configuration
  4. Customize to your liking
  5. Save and enjoy!
